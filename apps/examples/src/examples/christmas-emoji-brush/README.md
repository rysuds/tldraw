A festive emoji brush tool that draws Christmas emojis.

---

This example shows how to create a brush-like tool that draws random Christmas emojis (🎄🎅🎁🦌⛄❄️🎀🔔🌟) as you drag across the canvas. The tool is added to the toolbar with a custom santa hat icon.
